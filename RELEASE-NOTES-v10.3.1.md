# NileStock v10.3.1

- 7-day offline entitlement lease for paid plans; Free stays offline-capable indefinitely.
- Paid lease expiry temporarily falls back to Free feature access while preserving data and core selling.
- Reconnect revalidates plan/status and restores active paid access automatically.
- Refresh button restored.
- PWA install-state handling improved for Windows and installed standalone mode.
- Receipt paper selection now changes screen preview as well as PDF/print output.
- Customer Credit explicitly gated to Business. Existing Business/Pro page gates remain enforced.
- Added `/blog` with five SEO-targeted guides, article metadata/structured data and sitemap entries.

Web licensing note: a device that never reconnects cannot receive an instant remote revocation. The lease solves the normal offline-forever premium case for ordinary users; stronger anti-tamper enforcement would require signed offline licences or a packaged native/desktop app.
